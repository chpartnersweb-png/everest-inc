## 1. 制作の目的とコンセプト

**「家具・家電を、お手頃に。配送・設置までおまかせ。」**

最初に価格の手頃さを伝え、その後で「運べない」「配線が難しい」「引越しと一緒に相談したい」という負担を解消する。安く購入できることと、購入後に使い始めるまで任せられることを、ひと続きの価値として見せる。

主な成果は電話での購入相談・在庫確認。買取相談と、来店前の問い合わせも同じページで受け止める。Facebookは店舗からの発信を見るための補助導線とする。

### 想定する閲覧者

以下は制作上のターゲット仮説であり、実際の顧客属性や販売実績を示すものではない。

- 新生活や引越しに合わせて、家具・家電の初期費用を抑えたい方。
- 冷蔵庫・洗濯機などの買い替えにあたり、運搬や設置を依頼したい方。
- 家族向けの大型冷蔵庫・ドラム式洗濯機を探している方。
- 関東で家具・家電の出張買取を相談したい方。

### 情報の優先順位

1. 家具・家電をお手頃に購入できる。
2. 新生活向けセットの価格目安は25,000〜50,000円前後。組み合わせにより変動する。
3. 1点から配送・設置まで相談でき、配線・設置・動作確認は無料で対応する。
4. セット注文時には、距離に応じた無料の引越しサポートがある。
5. 家具・家電の買取、商品に応じた保証、希望時間の相談にも対応する。

## 3. デザイン方針

### 方向性：明るい暮らしの写真と、大きく読みやすい価格

温かい生活感と、地域で相談できる親しみやすさを両立する。写真を大きく使い、手頃さは価格と短い言葉で伝える。

- **メインカラー案：** 深いグリーン `#173F36`。会社名、見出し、ナビゲーションの基準色。
- **背景色案：** アイボリー `#F5F2E9`、白 `#FFFFFF`。明るい室内画像となじませる。
- **アクセント案：** オレンジ `#E58A2B`。価格のマーカー、電話導線、区切りに絞って使う。
- **本文色案：** チャコール `#242C29`。細かな条件も読みやすくする。
- オレンジ上の文字は濃色を基本とし、実装時にコントラストを確認する。
- 日本語は読みやすいゴシック体。価格・電話番号は桁が読み取りやすい数字を使う。
- 「お安く販売」を主題に、金額・商品画像・サービスの説明に視線を集める。

色は提案段階。Facebookのロゴ・既存カラーは内容未確認のため反映していない。

### レイアウト

ファーストビューは、明るい暮らしのイメージ画像を画面いっぱいに使用する。写真の余白に短い見出しと電話ボタンを重ね、写真自体を主役にする。

PCは画面高の80〜95％を目安に構成し、スマートフォンは見出し・電話ボタン・画像の主要部分が初期画面に収まるよう調整する。ヒーロー直後に新生活セットの価格目安を置き、価格までの距離を短くする。

下部は、価格を見せる横長の帯、商品写真と説明、サービスの図解、買取の色面、FAQを組み合わせる。同じカードの反復を避け、内容に合ったレイアウトにする。本文の横幅は約1,120〜1,200pxを目安とする。

## 5. 画像をすべて新規制作する計画

### 画像の使い方

提供写真がないため、暮らし・商品カテゴリ・サービスの説明用ビジュアルを新規制作する。写真調の生成画像と、独自制作のSVGアイコン・図解を組み合わせる。

- 写真調画像は、実在の在庫、販売実績、実店舗、所属スタッフを表す資料として使わない。
- ヒーローは「暮らしのイメージ（生成画像）」、商品カテゴリは「取扱商品のイメージ（生成画像）」、作業場面は「サービスのイメージ（生成画像）」を近接表示する。
- 商品写真と確定の型番・個別価格・在庫数を結びつけない。
- 生成した店構えや駐車場をアクセス案内に使わない。アクセスは住所・駐車台数・地図リンクで伝える。
- お客様の声、実績数、ビフォーアフター、スタッフのプロフィール写真は創作しない。
- 各画像の役割・生成日・生成指示・表示上の注意を `docs/GENERATED-ASSETS.md` に記録する。

画像制作は**写真調7点を初期想定**とする。ヒーローはPC・スマートフォンの2構図を含む。OGPはヒーロー素材と正式会社名を組み合わせた1点を派生制作する。生成結果に応じて再生成・トリミングを行う。

別途、配送・設置・動作確認・買取・時間相談・保証などを説明するSVGアイコン約6点、会社名の文字組み、faviconを制作する。正式ロゴの有無は未確認のため、既存ロゴを模した扱いにはしない。

### 共通する画像トーン

- 自然光、明るい中間色、木目、白、グリーンの小物を中心に統一。
- 高級モデルルームより、日常の住まいを想起できる適度な生活感。
- 極端な広角、強い光沢、不自然な配線・寸法、重複した取っ手を避ける。
- 人物を主役にせず、商品カテゴリ・暮らし・作業内容が分かる画角にする。
- 日本語、価格、電話番号、許可番号は画像へ生成せず、HTMLの文字として配置する。

### 画像制作と確認の順序

1. ヒーロー1案で明るさ・色・生活感の基準を決める。
2. 共通の色調に合わせてカテゴリ画像とサービス画像を制作する。
3. スマートフォン用ヒーローを展開し、実際の文字位置で構図を確認する。
4. 機器の形状・配線・人物の手などを確認し、不自然な画像を差し替える。
5. Web用のサイズと形式に変換し、表示品質と容量を確認する。

アクセス画像は制作せず、所在地を示す地図へのリンクを設置する。独自の案内図が必要な場合は、位置・入口を確認してから制作する。

## 6. UI・UXと問い合わせ導線

### 電話を中心にした行動設計

- PC：ヘッダーに電話番号、ヒーロー・セット案内・買取・ページ末尾に相談ボタン。
- スマートフォン：画面下に「電話で相談」「商品を見る」の固定導線を設置。「商品を見る」はページ内移動。
- 電話リンクは `tel:07020216621`。ボタンには電話発信につながることが分かる文言を使う。
- 問い合わせ箇所には「購入希望の商品・ご予算・お届け先、または売りたい品物をお伝えください」と添える。
- Facebookは「Facebookを見る」と明示した外部リンク。予約・メッセージ受付への対応状況が未確認のため、予約ボタンとして扱わない。
- 不定期営業のため、来店を促す箇所に事前の電話確認を添える。

### 読みやすさ・操作性

- モバイル本文は16px程度以上、補足条件は14px程度以上を目安にし、価格条件も読み取れる大きさを確保。
- ボタンの高さは44〜48px以上を目安に確保。
- 固定ヘッダー・下部バーが見出しや最終行を隠さないよう余白を設ける。
- メニューはキーボード操作・閉じる操作・フォーカス移動に対応する。
- FAQは標準の `details` / `summary` を基本とし、JavaScriptに依存せず開閉できるようにする。
- 画像内に重要な文字を埋め込まず、価格・条件・連絡先をテキストとして掲載する。
- 写真の上の文字は暗幕や余白を調整し、スマートフォンの切り抜きでも読めるようにする。

### 動き

短いフェードや軽い位置移動で、写真と見出しの登場を補助する。価格や電話ボタンはすぐに表示し、操作開始を待たせない。

標準スクロールを使い、常時動くカルーセルや自動再生動画は初期仕様に含めない。`prefers-reduced-motion` に合わせて動きを抑える。

## 7. Astroでの実装計画

### 基本構成

既存のAstroプロジェクトを使用する。調査時点では `src/pages/index.astro` は初期ページ、依存関係はAstroが中心の最小構成だった。

商品は在庫台帳ではなく、取り扱いカテゴリとして管理する。価格目安・電話・住所・サービス条件はデータへまとめ、同じ内容を各所で再利用する。

### スタイル・画像・JavaScript

- 全体の配色、文字、余白は `global.css` の変数で管理し、各セクションのCSSはコンポーネント内のスコープ付きスタイルを使う。
- 画像は `src/assets/generated/` に保存し、実装時にAstroの画像機能の公式資料を確認して出力サイズを調整する。
- PC・スマートフォンに合う画像を出し分け、ヒーローの主要画像は遅延読み込みしない。
- 下部画像は遅延読み込みし、画像サイズを確保して読み込み中のレイアウトの揺れを抑える。
- ナビゲーションと軽い演出に必要なJavaScriptだけを追加する。
- 買い物カート、会員登録、決済、在庫管理、問い合わせフォームは初期仕様に含めない。連絡先が提供されている電話とFacebookへ導線を絞る。

### 開発サーバー

リポジトリの `AGENTS.md` に従い、開発サーバーを開始する際は `astro dev --background` を使用する。管理には `astro dev status`、`astro dev logs`、`astro dev stop` を使う。コマンドの対応状況は実装時に確認する。

## 8. 検索・SNS共有の設計

検索で伝える主題は「千葉県佐倉市」「家具・家電販売」「買取」「配送・設置」。関東への出張買取・配送はサービス説明として自然に含める。

- タイトル案：`佐倉市の家具・家電販売・買取｜エベレスト株式会社`
- 説明文案：`千葉県佐倉市のエベレスト株式会社。家具・家電をお手頃に販売。1点から配送・設置まで対応し、関東の出張買取もご相談いただけます。新生活向けセットの価格目安は25,000〜50,000円前後。`
- 日本語設定、見出しの階層、画像の代替テキスト、OGP・SNS共有用画像を整備する。
- 正式な公開URL確定後にcanonical、robots.txt、sitemap.xmlを設定する。
- 構造化データは提供済みの会社名・住所・電話を中心に構成し、業態に適した型を実装時に確認する。
- 不定期営業を任意の曜日・時刻に置き換えない。座標・レビュー・評価点・個別商品の在庫や価格を追加しない。
- 生成画像を、実店舗・実在スタッフ・実在商品の証明となる構造化データ画像に使わない。
- OGPは会社名と暮らしのイメージを組み合わせ、実店舗写真として紹介しない。

検索順位やインデックス登録は制作完了とは別に扱う。公開後に実URLの応答と検索エンジン向け設定を確認する。

Facebookは提供リンクとして採用する。今回の環境では内容を取得できなかったため、投稿内容・既存ロゴ・実際の商品・営業情報は確認済み資料に含めていない。
